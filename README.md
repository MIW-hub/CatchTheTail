# Hey Chicken! — 꼬리잡기 파티게임

> 게임 이름은 Hey Chicken!입니다. 코드 모듈, 프로젝트 파일 이름은 그대로 `CatchTheTail`입니다.

로봇 캐릭터들이 정해진 목표 색의 배터리 꼬리를 빼앗는 멀티플레이 파티게임입니다. 1분마다 색이 바뀌며, 경기 종료 시 보유 꼬리 수를 기준으로 승자를 정합니다.

> 기획 기준 문서이자 현재 구현 현황입니다. 코드 위주로 작성했고, 에디터에서 직접 확인하지 못한 항목은 **미검증**으로 표시했습니다.

## 핵심 게임 흐름

```text
메인 메뉴 → 로비(맵·설정·Ready) → 로딩 → 카운트다운(5초) → 경기 → 결과 → 로비
```

1. 방장이 방을 열고(방 코드 공유), 참가자가 입장해 Ready 합니다.
2. 방장이 맵과 경기 설정을 고르고 시작하면, 참가자에게 서로 겹치지 않는 색을 무작위로 배정합니다.
3. 각 플레이어는 자신의 목표 색을 가진 상대의 꼬리를 잡습니다.
4. 꼬리를 잡으면 자신의 꼬리 수가 늘고, 잡힌 상대의 꼬리 수는 줄어듭니다.
5. 꼬리를 잃은 플레이어는 다음 라운드까지 유령 상태가 됩니다.
6. 라운드(기본 60초)마다 색과 목표를 다시 배정하고 유령을 부활시킵니다.
7. 전체 경기 시간이 끝나면 꼬리 수가 가장 많은 플레이어가 승리합니다. 동점이면 공동 승자로 처리하고, 일정 시간 뒤 대기 로비로 자동 복귀합니다.

## 게임 규칙

### 색상과 목표

| 순서 | 색 | HEX |
|---|---|---|
| 1 | 빨강 | `#E53935` |
| 2 | 주황 | `#FB8C00` |
| 3 | 노랑 | `#FDD835` |
| 4 | 초록 | `#43A047` |
| 5 | 하늘 | `#29B6F6` |
| 6 | 파랑 | `#2B3BFF` |
| 7 | 보라 | `#8E24AA` |
| 8 | 분홍 | `#FF4FA3` |

- 라운드마다 참가 인원만큼 색을 중복 없이 무작위 배정하고, 목표도 서로 겹치지 않게 정합니다 (`ACTGameMode::AssignColorsAndTargets`).
- 내 목표 색은 **나에게만** 알려 줍니다. 다른 플레이어의 목표나 나를 노리는 사람은 클라이언트에 복제되지 않습니다 (`TargetColor`는 `COND_OwnerOnly`).
- HUD에는 내 목표 색만 표시하고, 나를 노리는 사람은 전화부스로만 알아낼 수 있습니다.

### 시간과 행동

- 전체 경기 시간, 라운드 길이, 최대 인원, 시작 꼬리 수는 로비에서 방장이 정합니다 (`CTMatchSettings`). 기본값은 5분 / 60초 / 8명 / 꼬리 1개입니다.
- 시작 5초 카운트다운 동안에는 기믹 피격이 없고, 경기 단계(`Playing`)에서만 적용됩니다.
- 잡기와 밀기에는 쿨타임이 있고, 달리기는 시간 제한과 쿨타임이 있습니다. 값은 `BP_CTCharacter`에서 조절합니다.
- 목표가 아닌 상대는 밀어낼 수 있고, 밀려난 사람은 방향에 따라 앞으로 엎어지거나 뒤로 넘어졌다 일어납니다.
- 꼬리는 상대에게 빼앗기거나 기믹에 맞으면 바닥에 튕겨 나오고, 땅의 꼬리는 먹어서 얻을 수 있습니다 (`CTTailPickup`, 일정 시간 뒤 사라짐).

### 유령과 부활

- 꼬리를 모두 잃으면 유령이 됩니다. 이동 속도 0.5배, 이동만 가능하고 점프·달리기·잡기·밀기와 발소리는 없습니다.
- 다음 라운드 시작 시 부활합니다. 유령도 땅의 꼬리를 먹으면 그 자리에서 바로 부활합니다 (기권한 플레이어 제외).

### 기권

- 일시정지 메뉴(ESC)에서 경기 시간이 절반 지난 뒤 기권할 수 있습니다. 기권하면 꼬리를 모두 잃고 이번 경기 순위에서 제외됩니다.

### 승리

- 경기 종료 시 꼬리를 가장 많이 가진 플레이어가 승리합니다.
- 동점이면 공동 승자로 결과 화면에 표시합니다. 연장전은 구현하지 않았습니다.

## 입력

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 이동 | 카메라 회전 |
| Space | 점프 |
| Q | 꼬리잡기 |
| E | 밀기 |
| Shift 유지 | 달리기 |
| F | 전화부스 사용 (부스 안에서) |
| V 유지 | 음성 말하기 (근처 플레이어에게만 들림) |
| ESC | 일시정지 메뉴 |

설정 화면에서 키를 다시 지정할 수 있습니다 (`Esc` 및 다른 동작과 겹치는 키는 거부).

### 카메라 (자유 회전 3인칭)

- 이동은 카메라가 보는 방향 기준이고, 캐릭터는 이동하는 방향으로 몸을 돌립니다.
- 위/아래 각도에 따라 거리가 바뀝니다. 위에서 내려다볼 때는 멀리, 뒤에서 볼 때는 가깝게 보간합니다.
- 카메라가 벽에 막히면 스프링암이 당겨지고, 너무 가까우면 내 캐릭터를 숨깁니다.
- `BP_CTCharacter`의 `CT|Camera`에서 거리·기준 각도·곡선·시야각을 조절합니다.

속도 배율은 곱셈 대신 버프를 합산합니다 (설계 기준).

```text
최종 이동 속도 = 기본 이동 속도 × (1.0 + 적용 중인 버프 합계)
달리기 +0.5, 목표 추격 +0.2, 유령 0.5배 (달리기·추격 불가)
```

## 맵과 기믹

로비에서 맵을 고릅니다 (`CTMapSettings`, 프로젝트 설정 → CT Maps).

| 맵 | 레벨 | 특징 |
|---|---|---|
| 큐브 도시 | `L_City` | 기본 맵. 하늘에서 떨어지는 물체, 전화부스 |
| 시골 마을 | `L_Country` | 언덕, 부쉬, 굴러오는 통나무 |
| 작은 마을 | `L_Building` | 순환 도로(움직이는 차량), 폭발 드럼통, 광장·공원·시장·카페·배송 마당 |

| 기믹 | 클래스 | 동작 |
|---|---|---|
| 전화부스 | `ACTPhoneBooth` | 부스 안에서 F. 통화 중 이동 불가. 내 목표(거리와 방향 화살표) 또는 나를 노리는 사람(거리)을 알려 줌. 사용 후 재사용 대기(로비 설정) |
| 부쉬 | `ACTBush` | 안에 있으면 다른 화면에서 몸이 가려짐. 오래 숨으면 흔들려 들킴 (로비 설정으로 켜고 끔) |
| 낙하물 | `ACTFallingSpawnVolume` / `ACTFallingProp` | 하늘에서 떨어져 맞으면 날아가며 꼬리를 흘림 |
| 굴러오는 통나무 | `ACTRollingLog` | 지형을 따라 굴러가며 맞으면 날려 보냄 |
| 도로 차량 | `ACTRoadVehicle` | 순환 도로(스플라인)를 달리는 차. 치이면 날아가고 꼬리를 흘림. 서버 시간 기준으로 움직여 모든 화면이 같음 |
| 폭발 드럼통 | `ACTExplosiveBarrel` | 닿으면 3초 뒤 폭발해 반경 안의 플레이어를 날리고 꼬리를 흘림. 일정 시간 뒤 다시 나타남 |
| 꼬리 줍기 | `ACTTailPickup` / `ACTTailPickupSpawner` | 바닥에 놓인 꼬리를 먹으면 꼬리가 늘어남 |

## UI

### 인게임 HUD (`WBP_CTHUDWidget`)

- 왼쪽 위 **타겟 카드**(내 목표 색), 위 가운데 **시간 카드**(라운드, 남은 시간, 라운드 종료까지), 오른쪽 위 **순위표**, 왼쪽 아래 **내 꼬리**, 오른쪽 아래 **키 안내(Q/E/Shift)**.
- 순위표는 인원에 맞춰 줄이 늘어나고(`WBP_CTHudScoreEntryWidget`), 1등 왕관과 내 줄 강조가 있습니다.
- 키 안내 옆에 쿨타임이 정수 초로 표시되고, 키 칸 위를 어두운 덮개가 위에서 아래로 걷어 내며 쿨타임을 보여 줍니다 (`M_CT_CooldownRadial`, 이름만 남은 잔재).
- 오른쪽 가운데에 마이크 상태(흰 패널, 마젠타 마이크 아이콘, 파장 막대 3개)와 아래 키 이름이 있습니다. 말하는 중(V를 누름)에는 패널이 마젠타(#FF2783)로 바뀌고 아이콘과 막대가 흰색이 되며 막대가 출렁입니다. 설정에서 마이크를 끄면 회색이 됩니다.
- 시작 카운트다운, 대기 안내, 유령 안내, 전화부스 방향 화살표, 상단 안내 문구를 표시합니다.

### 그 외 화면

- **메인 메뉴 / 인트로**, **이름 입력**, **언어 선택**, **로비**(맵 선택, 경기 설정, Ready, 채팅, 방 코드), **로딩**, **일시정지 메뉴**(계속하기·설정·기권·종료), **결과**, **설정**(소리·화면·접근성·키 설정·이름 변경).
- 위젯 트리는 에디터 도구(`CTUIBuildTools`)로 구성할 수 있습니다. **HUD를 다시 만들면 직접 조정한 값이 초기화되므로**, 지금 생성 코드는 조정된 위치·글자 크기를 기준으로 맞춰 둔 상태입니다.

## 사운드

- BGM 2곡과 효과음(버튼 올림/확인/뒤로, 점프·착지, 발소리, 꼬리 획득·잃음, 밀기, 카운트다운, 라운드 시작, 유령 부활, 승리)을 `UCTAudioSubsystem`으로 재생합니다.
- 발소리는 애니메이션 노티파이(`CTAnimNotify_Footstep`)로 걷기·달리기·뒤로 걷기에 넣었고, 유령은 내지 않습니다.
- 음악·효과음 볼륨과 전체 음소거는 설정에서 저장됩니다.
- **근접 음성 채팅:** Steam 음성을 켜 두었고(`bHasVoiceEnabled`, `bRequiresPushToTalk`), 눌러서 말하기(기본 V)로 말합니다. 목소리는 말하는 캐릭터 위치에서 거리에 따라 작아지다가 안 들립니다 (기본 5m 안은 최대 크기, 그 뒤 15m에서 사라짐, `BP_CTCharacter`의 `CT|Voice`에서 조절). 설정 화면에 마이크 사용, 음성 볼륨, 마이크 감도가 있고, 눌러서 말하기 키는 조작 방법에서 바꿀 수 있습니다.

## 번역

- 한국어 원문을 키로 쓰는 번역표 `Config/Localization/Game_Translations.tsv` (`원문 → 영어 → 일본어`)를 관리합니다.
- 새 문구를 추가한 뒤 에디터를 끄고 `Tools\UpdateLocalization.bat`을 실행하면 수집 → 번역 반영 → 컴파일이 진행됩니다.
- 칸이 좁은 곳은 줄임말을 쓰고(예: 목표 없음 → None / なし), HUD의 긴 문구는 칸에 맞게 자동으로 작아지도록 했습니다.

## 코드 구조

| 폴더 | 주요 클래스 |
|---|---|
| `Core` | `ACTGameMode`(색 배정, 라운드·승패), `ACTGameState`(시간·라운드·단계·결과), `ACTLobbyGameMode`, `UCTGameInstance`, `UCTSessionSubsystem`(Steam 방), `UCTSettingsSubsystem` / `UCTAudioSubsystem`, `FCTMatchSettings`, `UCTMapSettings`, 에디터 도구(`CTUIBuildTools`, `CTLocalizationTools`, `CTAnimBuildTools`) |
| `Player` | `ACTCharacter`(이동·카메라·잡기·밀기·달리기·유령), `ACTPlayerController`, `ACTLobbyPlayerController`, `ACTMenuPlayerController`, `ACTPlayerState`(색·목표·꼬리 수·유령·기권) |
| `Tail` / `Tongue` | `ACTTail`(꼬리 외형), `UCTTongueComponent`(꼬리 흔들림) |
| `Animation` | `UCTAnimInstance`, 잡기 판정 노티파이 상태, 발소리 노티파이 |
| `World` | 위 기믹 클래스들 |
| `UI` | HUD, 순위표 줄, 결과, 로비, 메인 메뉴, 일시정지, 로딩, 설정, 전화 팝업, 방향 화살표 등 |

- 서버가 색 배정, 잡기 판정, 점수, 라운드 전환, 유령 전환, 기믹 피격을 결정하고, 클라이언트는 입력을 보내 복제된 상태를 표시합니다.
- 설정값은 `UPROPERTY`로 노출하고 `.h` / `.cpp`를 분리하며 한국어 주석을 사용합니다.

## 빌드와 실행

```text
빌드:   Engine\Build\BatchFiles\Build.bat CatchTheTailEditor Win64 Development -Project="<경로>\CatchTheTail.uproject"
번역:   Tools\UpdateLocalization.bat   (에디터를 끄고 실행)
패키징: Tools\PackageGame.bat [Shipping]   (에디터를 끄고 실행, 결과는 Packaged\Windows)
```

시작 맵은 `L_Mainmenu`, 인스턴스 클래스는 `CTGameInstance`입니다. 에셋(`.uasset`, `.umap`)은 Git LFS로 관리합니다.

## 검증 현황

- 컴파일과 패키징 테스트는 확인했습니다.
- 다음은 에디터/멀티플레이에서 **아직 직접 확인하지 못했습니다**: 새 HUD 배치의 실제 모양, 도로 차량·폭발 드럼통의 서버/클라이언트 동기화, 전화 조회(목표/헌터)의 복제 변경 이후 동작, 언어별 UI 넘침(특히 일본어), 다인 접속 시 순위표 8줄, 음성 채팅(패키징 빌드에서 마이크 두 대로 확인 필요).

## 남은 결정 사항

- 기본 경기 시간과 시작 꼬리 수, 점수 정의(보유 꼬리 수 / 누적 획득 수)의 최종 확정.
- 동점 처리(연장전 도입 여부)와 3명 이상 동점 규칙.
- 잡기 거리·밀기 힘·기본 이동 속도 등 테스트값 조정.
- 진행 중 참가·퇴장, 방장 종료 등 세션 예외 처리.
- 공장 구역(`L_Building`) 기믹 추가 여부 (증기 파이프, 컨베이어 등).
