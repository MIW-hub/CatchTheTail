## 완료

- **기반:** 프로젝트, Git, 기본 클래스 5종, 테스트 맵(TypeA), PlayerStart, 탑다운 카메라
- **캐릭터:** 닭 로봇 모델, 머티리얼, 8색 적용, 이동·점프·달리기, 잡기·밀기 몽타주 코드
- **꼬리:** 꼬리 모델·머티리얼(색 + 이미시브 + 맥동), `ACTTail`(잡히면 불 꺼짐·회색), `Hips` 본 부착
- **규칙:** 색 배정·목표 색, 서버 잡기 판정(거리·색·대상 검증), 점수·유령·부활, 승패 처리
- **UI:** HUD, 점수판, 결과 화면 (C++ + WBP)
- **연출:** 혀 흔들림, 세미카툰 포스트 프로세스
