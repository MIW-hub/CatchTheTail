# Hey Chicken! — 진행 현황 (2026-11-18)

예전 주차별 표는 지금과 맞지 않아 현재 상태로 바꿨습니다. 자세한 구현 내용은 `docs/tech/`와 각 모드 문서를 보세요.

## 완료

- **모드:** 꼬리잡기(개인전), 보물찾기(4:4 팀전). 규칙은 게임 규칙 클래스로 분리
- **게임 흐름:** 메인 메뉴, 로비(맵·설정·Ready·팀), 로딩, 카운트다운, 경기, 결과, 로비 복귀, 보물찾기 라운드 사이 결과 팝업
- **온라인:** EOS P2P(기기 ID 로그인, 방 코드 검색), 근접 음성과 팀 음성, 두 인스턴스 자동 시험 7종
- **AI:** 꼬리잡기와 보물찾기 AI, 이동 지도(NavMesh) 없는 맵에서 막힘 우회
- **UI:** 3개 국어, 보물찾기 HUD·결과·라운드 팝업, 8명 로비, 전적 기록
- **사운드·연출:** 효과음, 상체 몽타주(들기·던지기), 에너지 낙하·터짐
- **출시:** Shipping 패키징, 제출용 폴더, 스토브 심사 진행

## 보류·진행 중

- 축구 모드(`docs/Mode_Football_Plan.md`): 전용 경기장이 필요해 보류
- 두 대 이상 PC에서 던지기·잡기 동기화 직접 확인, 밸런스 조정(다수 테스트 필요)
- 꼬리잡기 첫 흰색 깜빡임 (보류)

## 알려진 한계

- 팀 점수 복제 변경으로 이전 빌드와 호환되지 않음 (모두 같은 빌드를 사용)
