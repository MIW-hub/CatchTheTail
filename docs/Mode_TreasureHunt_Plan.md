# 🎮 보물찾기 모드 — 기획서 (초안)

> 작성일: 2026-11-13 · 상태: **규칙 확정 v7** (2026-11-13, AI 참가 가능으로 변경)
> 전제: 기존 꼬리잡기 모드는 그대로 유지하고, 로비에서 모드를 고르는 방식으로 추가합니다.
> 용어: **에너지** = 맵에 놓인 수집 아이템(기존 꼬리 아이템을 확장). **꼬리** = 모은 에너지의 시각 표현.

---

## 1. 한 줄 요약

4:4 팀전. 맵에 흩어진 에너지 100개를 더 많이 모은 팀이 라운드를 이기고, 3라운드 중 더 많이 이긴 팀이 최종 승리합니다. 상대에게 오브젝트를 던져 맞히면 상대가 모은 에너지의 절반이 떨어집니다.

---

## 2. 규칙

### 2-1. 경기 구성
| 항목 | 내용 |
|---|---|
| 인원 | 최대 4:4 (총 8명). **8명보다 적어도 시작 가능** |
| 시작 조건 | 양 팀에 **각각 1명 이상**(사람 또는 AI) 있고, 방장을 제외한 **모든 사람이 Ready** 한 상태 (한 팀이 0명이면 시작 불가). AI는 Ready 개념이 없음 |
| 라운드 | 총 3라운드, 라운드 시간 1~2분 (맵 설정에서 선택) |
| 승리 | 라운드마다 팀 합산 에너지가 많은 팀이 승리, 라운드 승점이 더 많은 팀이 최종 승리 |
| 라운드 동점 | **에너지가 같으면(예: 50:50) 두 팀 모두 승점 1점 증가** |
| 시작 위치 | 매 라운드 시작 시 무작위 위치에 스폰. 단, **벽이나 오브젝트에 끼거나 파묻히는 위치는 제외** (2-8 참고) |
| 팀 색 | 팀마다 색을 무작위로 정하고, **같은 팀은 모두 같은 색** |

### 2-2. 에너지와 꼬리
- 맵에는 에너지가 **총 100개** 스폰됩니다.
- 에너지를 먹을 때마다 **개인 에너지**가 늘고, 팀 에너지는 팀원 개인 에너지의 합입니다.
- **꼬리 길이는 에너지에 비례**합니다. 에너지 10개당 꼬리 1개 길이입니다.
- 결과 화면에서 개인이 라운드 안에서 먹은 에너지를 합산해 점수로 보여줍니다.

### 2-3. 오브젝트 던지기 (핵심 상호작용)
- 맵마다 **그 맵 전용 던지기 오브젝트 한 종류**를 정해 두고, 맵 곳곳에 **20개씩** 배치합니다. 오브젝트는 **농구공처럼 물리가 적용되어 월드에 계속 남아 있는 물체**입니다. 던진 뒤에도 사라지지 않고 그 자리에 굴러다니며 **다시 집어서 던질 수 있습니다.** 새로 생성되는 오브젝트는 없습니다(재생성 없음). 라운드가 시작될 때마다 20개를 처음 배치 상태로 되돌립니다(남은 개수를 이어 가지 않음).
- **잡는 키는 꼬리잡기 키와 같고**, 쿨타임도 꼬리잡기와 같은 값을 씁니다. 던지기에는 따로 쿨타임이 없습니다.
- **한 번에 하나만** 들 수 있습니다. 들고 있는 동안에는 다른 오브젝트를 잡을 수 없고, **던진 뒤에야 다시 잡을 수 있습니다.**
- 들고 있는 동안에도 **달리기와 점프를 할 수 있습니다.** 들고 있는 시간에 **제한이 없어** 일정 시간 뒤 저절로 떨어지지도 않습니다.
- 던지는 키는 **꼬리잡기 키를 다시 누르는 방식**이고, 던지는 힘과 사거리는 **고정값**입니다.
- 오브젝트를 잡을 수 있는 거리는 **약 6m**로 시작하고, 꼬리잡기 거리와 비교해 테스트한 뒤 정합니다.
- **같은 키를 눌렀을 때 우선순위는 꼬리가 먼저, 그다음이 오브젝트**입니다. 꼬리를 잡을 수 있는 거리에 상대 꼬리가 있으면 꼬리잡기, 없으면 가까운 오브젝트를 잡습니다.
- **던지는 방향은 카메라나 조준 방향이 아니라 캐릭터가 바라보는 방향**입니다.
- 던지기 전에 **궤적(날아갈 경로)을 던지는 본인에게만 미리 보여줄 수 있습니다**(선택 기능, 다른 플레이어 화면에는 보이지 않음).
- 던진 오브젝트에 맞은 캐릭터는 **자신이 모은 에너지 수의 절반(내림)을 떨어뜨립니다.** (단위는 에너지 개수, 꼬리는 에너지의 시각 표현)
  - 에너지가 1개면 1개가 떨어짐 (내림해서 0이 되면 최소 1개)
  - 에너지가 0개면 아무것도 떨어지지 않음
  - 예: 5개 → 2개, 4개 → 2개, 1개 → 1개
- **아군이 던진 오브젝트에도 아군이 맞을 수 있고**, 맞으면 똑같이 에너지가 떨어집니다 (아군 피해 있음).
- 떨어진 에너지는 바닥에서 다시 주울 수 있습니다.
- 맞은 캐릭터의 에너지가 줄면 꼬리 길이도 같은 비율로 줄어듭니다(10개당 1개 길이).
- **맞는 대상에는 잡혀서 멈춘 사람과 잡고 있는 사람도 포함**됩니다(2-4 참고).

### 2-4. 꼬리 잡기 (이 모드에서의 변경)
- 꼬리잡기는 **가능하지만 꼬리를 빼앗지 않습니다.**
- 잡으면 상대가 **약 2초 멈춥니다.** 기존 꼬리잡기 애니메이션을 그대로 씁니다.
- 잡힌 동안에도 **무적이 아닙니다.** 잡은 쪽과 잡힌 쪽 모두 던진 오브젝트에 맞을 수 있습니다. 상대를 멈추게 해서 던져 맞히기 쉽게 만드는 것이 꼬리잡기의 목적입니다.
- 꼬리 대결(연타)은 쓰지 않습니다.

### 2-5. 유령과 부활
- **이 모드에는 유령 상태가 없습니다.**

### 2-6. 정보 공개 (HUD)
- 화면 위쪽에 **라운드 승리 수**와 **현재 라운드 수**를 표시합니다.
- 알 수 있는 에너지 정보: **우리 팀 에너지와 내 에너지**.
- **상대 팀 에너지 수치는 알 수 없고**, 상대 캐릭터의 꼬리 길이를 보고 예측해서 던질 대상을 정합니다.

### 2-7. 음성
- 기존 근접 음성은 **그대로** 동작합니다(눌러서 말하기 V).
- **팀 음성**을 새로 추가합니다. `T` 키를 누르면 **팀원에게만, 거리와 상관없이 멀리 있어도** 들립니다(무전기 방식).
- "버튼 없이 말하기(상시 음성)"를 켠 경우, **상시 전송은 팀 음성만** 적용됩니다. 상대 팀과 대화하려면 `V` 키를 눌러야 합니다.

### 2-8. 라운드 시작 위치 (무작위 스폰)
- 매 라운드 시작 때 플레이어마다 무작위 위치를 새로 정합니다(이전처럼 고정된 PlayerStart를 쓰지 않음).
- 위치 조건:
  1. 갈 수 있는 바닥 위일 것 (이동 가능 영역에서만 뽑음)
  2. 캐릭터 크기만큼의 공간이 **벽, 오브젝트와 겹치지 않을 것** (끼이거나 파묻히지 않게 충돌 검사)
  3. 다른 플레이어와 **거리를 두고 스폰**할 것. 거리 규칙은 **팀과 상관없이 모든 플레이어에게 똑같이** 적용합니다. (3m와 8m 중 어느 값을 쓸지는 3-2의 3번 참고)
- 조건을 만족하는 위치를 못 찾으면 맵에 미리 둔 안전 스폰 지점 후보로 대체합니다.
- "가려지면 안 된다"를 **벽이나 오브젝트에 가려져 보이지 않거나 끼이는 위치를 피하라**는 뜻으로 이해했습니다. 다르면 알려 주세요.

### 2-9. 로비 팀 편성과 팀 변경
**팀전 모드를 고르면 로비의 `참가 플레이어` 패널이 위아래 두 칸(레드팀, 블루팀)으로 나뉩니다.**

**기본 배치**
- 방에 들어온 순서대로 **레드 → 블루 → 레드 → 블루…** 로 자동 배치됩니다.
- 로비에서 **자유롭게 팀을 바꿀 수 있습니다.** (팀 변경 버튼)

**팀 변경 흐름**
1. 팀 변경 버튼을 누릅니다.
2. 이동하려는 팀에 **자리가 있으면 바로 이동**합니다.
3. 이동하려는 팀이 **이미 4명이면 바로 이동하지 않습니다.** 대신 **모든 플레이어 화면에 요청 패널**이 뜹니다.
4. 패널에는 **요청한 플레이어 이름, 팀 변경 신청 버튼, 5초짜리 원형 진행 표시**가 있습니다.
5. 요청이 떠 있는 **그 순간에만**, 이동하려는 팀(4명인 팀)의 플레이어가 **팀 변경 버튼으로 수락**할 수 있습니다. 수락하면 두 사람의 팀이 서로 맞바뀌고 패널은 사라집니다. 요청자와 같은 팀 사람은 수락할 수 없습니다.
6. 5초 안에 아무도 수락하지 않으면 패널이 사라지고 이동하지 않습니다.

**요청 규칙**
- 요청이 여러 개면 **개수만큼 패널이 차례로 쌓여** 뜹니다.
- 요청 후 **5초가 지나야 다시 신청**할 수 있고, **같은 사람이 중복 신청할 수 없습니다.**
- 요청 패널 안에는 이름, 신청 버튼, 원형 진행 표시 세 가지만 들어갑니다.

**Ready와 팀 변경**
- **Ready 상태에서는 팀 변경이 불가능**합니다. Ready를 취소한 뒤에 변경할 수 있습니다.

**팀 이름과 색**
- 레드팀, 블루팀은 **예시 이름**입니다. 실제 팀 색은 **팀마다 무작위로 정해지고 같은 팀은 모두 같은 색**입니다(2-1).
- 로비에서 두 팀을 어떻게 구분해 표시할지는 3-2의 4번 참고.

### 2-10. AI 플레이어 (보물찾기에서도 참가)
> 2026-11-13 변경: 이전에는 보물찾기에서 AI로 채우지 않기로 했으나, **AI와 함께 플레이할 수 있게** 바꿉니다(혼자서도 테스트와 플레이 가능).

**참가와 팀 배정**
- 로비의 **AI 인원 설정**(기존 항목)을 그대로 씁니다. 사람과 AI를 합쳐 최대 8명(4:4)입니다.
- AI는 경기 시작 때 만들어지고, 팀 배정은 **사람이 정한 팀 인원을 바꾸지 않고 인원이 적은 팀부터 채웁니다**(같으면 번갈아).
- 사람 한 명과 AI만으로도 시작할 수 있습니다(예: 사람 1명 팀 대 AI 1명 팀). 양 팀에 각각 1명 이상(사람 또는 AI)이면 됩니다.
- 로비 플레이어 목록에는 AI가 어느 팀에 들어갈지 **예상 위치로 표시**합니다(기존 AI 표시와 같은 방식).

**AI의 행동 (보물찾기용)**
| 행동 | 내용 |
|---|---|
| 에너지 수집 | 가까운 에너지를 우선 주워 모음(에너지가 많은 쪽으로 이동) |
| 오브젝트 | 근처 오브젝트를 집고, 상대 팀 캐릭터가 사정거리 안에 있을 때 던짐. 아군에게는 던지지 않도록 조준 |
| 꼬리잡기 | 잡으면 2초 멈춤, 잡힌 AI도 같은 규칙. 빼앗기 없음 |
| 팀 인식 | 같은 팀과 상대 팀을 구분해서 행동. 상대 에너지는 알 수 없고 **꼬리 길이로 추정** (사람과 같은 정보만 사용) |
| 라운드 | 사람과 같은 무작위 스폰과 3라운드 규칙을 따름. 유령 없음 |
| 음성 | 없음 (기존과 같음) |

**난이도**: 처음에는 한 가지(보통)만 만들고, 이동 속도와 던지기 정확도, 반응 시간으로 나중에 조절합니다.

## 3. 질문과 확정 사항

### 3-1. 확정됨
| 항목 | 확정 내용 |
|---|---|
| 떨어지는 단위 | **에너지 수**의 절반, **내림** (1개면 1개, 0개면 0개) |
| 라운드 초기화 | 에너지 100개 새로 배치, 개인 에너지와 꼬리를 0으로 초기화 |
| 라운드 동점 | 50:50이면 **두 팀 모두 승점 +1** |
| 최종 동점 | **무승부 표시** |
| 아군 피해 | 있음 (아군이 던진 오브젝트에 아군이 맞으면 똑같이 에너지가 떨어짐) |
| 팀 음성 | 거리와 상관없이 팀원에게만 들림 (무전기 방식) |
| 시작 위치 | 라운드마다 무작위 스폰. 벽·오브젝트에 끼면 안 됨 |
| 인원 | 8명보다 적어도 시작 가능. **양 팀 각 1명 이상** + **모두 Ready**일 때 시작 |
| 팀 편성 | 입장 순서대로 레드 → 블루 → 레드…, 로비에서 자유롭게 변경 (2-9) |
| 던지기 오브젝트 | 맵마다 한 종류, **맵당 20개** 곳곳 배치, **물리가 적용된 오브젝트(농구공처럼)**, 던진 뒤에도 남아 다시 집을 수 있음, **재생성 없음**, 라운드마다 20개로 초기 배치, **한 번에 하나** |
| 들고 있는 동안 | 달리기, 점프 가능, 시간 제한 없음(저절로 떨어지지 않음) |
| 던지는 키와 힘 | 꼬리잡기 키를 다시 누름, 고정 힘과 고정 사거리 |
| 8명 미만 AI | **AI도 보물찾기에 참가할 수 있음** (v7에서 변경, 2-10 참고). 로비의 AI 인원 설정을 그대로 사용 |
| Ready와 팀 변경 | Ready 중에는 팀 변경 불가(취소 후 가능) |
| 팀 변경 수락 | 요청이 떠 있는 동안 이동하려는 팀의 플레이어만 수락 가능 |
| 던지는 방향 | **캐릭터가 바라보는 방향**(카메라·조준 방향 아님). 궤적은 던지는 본인에게만 보여줘도 됨 |
| 잡기 우선순위 | 같은 키에서 **꼬리 먼저, 그다음 오브젝트** |
| 잡기와 던지기 | 키와 쿨타임은 꼬리잡기와 같음. 던지기에 별도 쿨타임 없음. 잡는 거리 약 6m(테스트 후 확정) |
| 잡힌 동안 | 맞을 수 있음 (무적 아님). 잡고 있는 사람도 맞을 수 있음 |
| 에너지 스폰 | 라운드 시작 때 100개 배치 |
| 개인 점수 | 라운드 동안 먹은 총량 |
| 스폰 거리 | 팀과 상관없이 모든 플레이어에게 똑같이 적용 (값은 3-2의 3번) |

### 3-2. 마지막으로 확정된 항목 (2026-11-13)
| 항목 | 확정 내용 |

## 6. 기술 위험

1. **팀 음성(가장 큰 불확실성)**: 현재는 거리에 따라 작아지는 근접 음성입니다. 팀원에게는 멀리서도 들리고 상대에게는 들리지 않게 하려면 음성 전달을 제어해야 합니다. 기본 구상은 다음과 같습니다.
   - 말하는 사람이 `T`를 누르는 동안 "팀 음성 중"이라는 상태를 모든 화면에 알립니다.
   - 듣는 쪽 화면에서 말하는 사람이 **팀원이고 팀 음성 중이면** 거리 감쇠를 끄고 똑바로(2D) 재생합니다.
   - 말하는 사람이 **상대 팀이고 팀 음성 중이면** 그 사람의 목소리를 내 쪽에서 소리 0으로 만듭니다.
   - 상태가 바뀌는 순간의 짧은 앞부분이 새어 나갈 수 있습니다.
   - 방식이 실제로 되는지 1주차에 작은 프로토타입으로 확인합니다.
2. **오브젝트 던지기 복제**: 던진 물체의 궤적과 피격을 모든 화면에서 같게 보이게 하는 것이 필요합니다. 서버가 피격을 판정하고 클라이언트는 연출만 하도록 설계합니다.
3. **에너지 100개의 복제 부담**: 아이템이 많아서 복제 비용과 가시 범위 처리를 확인해야 합니다. 먹은 순서 충돌(두 명이 동시에 먹기)은 서버가 먼저 처리하는 쪽에 점수를 줍니다.
4. **8명 라운드 재시작**: 위치 재배치 때 끼임, 겹침을 막는 스폰 지점 후보가 필요합니다.
5. **기존 꼬리잡기와의 회귀**: 규칙 분리 때 꼬리잡기가 깨지지 않는지 매번 확인해야 합니다.
