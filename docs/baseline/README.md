# 꼬리잡기 기준선 (회귀 확인)

모드 구조를 바꾸는 동안 **꼬리잡기가 기존과 똑같이 동작하는지** 확인하기 위한 기준 기록입니다.

## 쓰는 법
에디터를 끄고 실행합니다.

```powershell
# 기준선 만들기 (이미 만들어 둠: before)
powershell -File Tools\CTBaseline.ps1 -Name before

# 단계를 끝낸 뒤 기준선과 비교
powershell -File Tools\CTBaseline.ps1 -Name step1 -CompareTo before
```

- 경기 맵(`L_Building`)을 직접 실행하고 AI 3명, 경기 45초, 라운드 18초로 짧게 한 판을 돌려 `[CT]` 흐름 로그를 모읍니다. 게임 종료 로그가 나오면 자동으로 끝납니다(약 1분).
- `<이름>.log`: 전체 로그, `<이름>.events.txt`: 흐름 로그, `<이름>.skeleton.txt`: 비교용 뼈대.
- 비교는 **뼈대**만 합니다. AI가 누구를 잡는지, 아이템이 몇 개 남았는지는 판마다 달라서 뺐습니다.

## 기준선(before)의 뼈대
```text
AI 플레이어 3명 추가 (사람 1명, 요청 3명)
라운드 1 시작
게임 시작: 전체 45초, 라운드 18초
라운드 2 시작
라운드 3 시작
게임 종료: 승자 N명, 동점=?
```
- 같은 조건으로 두 번 돌려서 뼈대가 같은 것을 확인했습니다(before, before2). 잡기와 꼬리 보충 줄만 판마다 다릅니다.

## 이 확인이 보장하는 것과 못 하는 것
- 보장: 경기 시작, AI 채우기, 라운드 3번 진행, 경기 종료와 결과 계산, 잡기 처리 호출이 오류 없이 이어지는지.
- 못 보는 것: 화면(HUD, 결과 위젯), 음성, 이모트, 로비 흐름. 이것들은 단계마다 직접 한 판 확인하는 체크리스트(`docs/ModeArchitecture_Design.md`의 5번)로 봅니다.
